Overview

Made in Heaven - Spell Pack Lite is a reduced fork of Angel's Made in Heaven - Spell Pack. It intentionally keeps only the three spell-pack components used by this build while preserving their original content and WeiDU component numbers.

  • #0 Arcane Spellpack - Original wizard, sorcerer and bard spells.
  • #2 Divine Spellpack - Original cleric, druid and shaman spells.
  • #4 Planescape Torment Spellpack - A selection of spells from Planescape: Torment.

The Lite build also contains the custom Infinity UI++ compatibility fix that prevents SFO class/kit metadata such as {K=...,C=...} from leaking into Infinity UI++ class-level displays.

Compatibility

The supported game targets are inherited from the original components: BGEE, BG2EE, EET, classic BG2: ToB and BGT where allowed by the component installer.

The technical mod folder remains mih_sp and the original component IDs #0, #2 and #4 are preserved for WeiDU log, reinstall and uninstall compatibility with the previous custom three-component build.

Installation

Extract the archive into the game directory so that the mih_sp folder and setup-mih_sp installer are placed next to the game executable, then run the installer normally.

If replacing an older custom build, use the same setup-mih_sp installer so WeiDU can recognize the preserved component IDs.

Components

#0 - Arcane Spellpack

Adds the original Made in Heaven wizard, sorcerer and bard spells. See the full Arcane Spell List.

#2 - Divine Spellpack

Adds the original Made in Heaven cleric, druid and shaman spells. See the full Divine Spell List.

#4 - Planescape Torment Spellpack

Adds a selection of spells adapted from Planescape: Torment, including Ball Lightning, Stygian Ice Storm, Deathbolt, Mechanus' Cannon and Rune of Torment.

Configuration

The remaining relevant expert options are stored in mih_sp/mih_sp.ini. Options belonging only to components excluded from the Lite build have been removed from the Lite metadata file.
